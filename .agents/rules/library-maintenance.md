# Medhavat Animation Library — AI Assistant Rules

> Read `CONTRIBUTING.md` at the repo root before making any change to this project.
> The rules in `CONTRIBUTING.md` are authoritative. These rules below are quick-reference enforcement notes.

---

## Critical Rules (Never Break These)

1. **Every new animation element must be registered in TWO places simultaneously:**
   - `src/hub.js` → add an entry to the `ELEMENTS` array (all fields required)
   - `vite.config.js` → add the entry to `rollupOptions.input`
   Doing one without the other is an error.

2. **All element code lives in its own dedicated folder** at the repo root. Never add element-specific code to `src/hub.js`, `src/hub.css`, or `index.html`.

3. **Never create `package.json` inside an element folder.** All dependencies belong in the root `package.json`.

4. **Never modify `vendor/three/` directly.** Update Three.js via `npm install three@version` at the repo root.

5. **Never manually edit `public/frame-manifest.json`.** It is auto-generated by `scripts/generate-manifest.js`.

6. **`tslOperatorPlugin` in `vite.config.js` must never be removed.** It is required for Three.js TSL compute shaders in `jellyfish-simulation-app`.

## ⚠️ IP, Attribution & Professionalism Policy (NON-NEGOTIABLE)

> **This policy applies to AI coding assistants with the same force as human contributors. Read Section 10 of CONTRIBUTING.md for the full policy.**

### Attribution Header Rule
Any source file (`.js`, `.glsl`) that is derived from or substantially inspired by external code MUST have an attribution header comment at the top:

```js
/**
 * [Module Name] — [Brief Purpose]
 *
 * Original work by: [Author Name] ([URL])
 * Source:           [Repository or URL]
 * License:          [License Name] © [Year] [Author]
 *
 * Modifications by Medhavat Technologies:
 *  - [Describe what was changed]
 */
```

### Credits Section Rule
Every element `README.md` MUST end with a `## Credits & Acknowledgments` section that:
- Names every third-party library used (with URL and license)
- Names every external concept reference or inspiration source (even if no code was copied)
- Uses a legal note for any borderline attribution cases

**Omitting credits is a blocking error. Do not leave them empty or as a placeholder.**

### License Compatibility
Only use code under: **MIT, Apache 2.0, BSD 2/3-Clause, PDDL, CC0, ISC**.

DO NOT use: GPL, LGPL, AGPL, CC BY-NC, CC BY-ND, SSPL, or unlicensed code.

> A GitHub repo with no `LICENSE` file is NOT open source. All rights are reserved by default. Do not copy from unlicensed repos.

### AI-Specific Prohibitions
- **Never reproduce a full Shadertoy shader** without verifying the author's license and adding attribution.
- **Never remove or alter existing credit comments** in source files.
- **Never remove or alter the Credits section** of any README.
- **Proactively add attribution** whenever generating code based on a known external technique.
- **If the license of a source is unknown → stop and ask the maintainer before proceeding.**

### Respectful Attribution Etiquette
- Credit authors by name, not just URL.
- Use genuinely appreciative language — we respect the open-source community.
- Do not bury credits. They go in a dedicated, visible section.

## Folder Naming Convention

| Element Type | Suffix | Example |
|---|---|---|
| Three.js / WebGL 3D scene | `-scene` | `particle-field-scene` |
| App with full UI | `-app` | `distortion-app` |
| Reusable controller | `-controller` | `parallax-controller` |

All names must be `kebab-case`.

## WebGPU / Three.js TSL Safety Rules

- Always `await renderer.init()` before accessing any renderer backend properties.
- Always use `renderer.computeAsync()` for GPU compute dispatches.
- Guard deprecated or version-sensitive API calls:
  ```js
  if (typeof kernel.updateDispatchCount === 'function') {
    kernel.updateDispatchCount();
  }
  ```
- Three.js version is pinned in `package.json`. Do not upgrade without testing all TSL elements.

- `npm run build` → exits code 0, element HTML listed in dist output
- Every modified/added source file has attribution header if external code was used
- Every modified/added README has a Credits section with legal notes
